# zot

This chart deploys zot, the OCI registry that caches the images and
charts the cluster pulls. The wrapper pins the upstream zot chart and
carries the cluster-specific pieces: the internal route, the gateway
and mesh authorisation policies, the sync credentials ExternalSecret,
the service account and the PodDisruptionBudget.

## Components

- `values.yaml` — the zot configuration: sync, retention,
  resources and the data volume.
- `generated.yaml` — generated by `generate.py` from `census.json`.
  Do not edit by hand. Argo CD passes it as an extra values file.
- `census.json` — the census record: every image and chart pin the
  generator must cover.
- `pin-state.json` — the replaced pins of the last pin change.
  Retention keeps the current pins plus these, so a replaced digest
  stays pullable for one rollback window. It also carries the
  `dhi_poll` flag: the dhi.io sync entry stays on-demand until the
  Step 4 proof lands, then the flag flips and the generator
  emits the dhi.io poll entry.
- `cidrs.json` — one /32 per node: the base address of the node pod
  CIDR. The route SecurityPolicy allows exactly these sources.
  Regenerate with `generate.py --cidrs`.
- `templates/` — the internal HTTPRoute, the SecurityPolicy, the
  AuthorizationPolicies, the sync ExternalSecret, the service
  account and the PodDisruptionBudget.

## Upgrades

Re-run Gate 2 after every zot upgrade. Gate 2 is the live
verification set for the registry: a pinned image pull and an
on-demand pull, each digest-exact, a pull attempt from an ordinary
pod denied, and the metrics scrape answering with the zot target
up. An upgrade is not done when the pod is healthy. It is done
when Gate 2 passes on the new version.

## Before maintenance

zot is an accelerator, never a dependency. Before Longhorn, gateway
or internal DNS maintenance, remove the node mirror block or scale
zot to zero and prove direct pulls work. Charts need no equivalent
action: chart renders fall back to the upstream chart repositories
on their own when zot does not answer.

## Access

No local users exist in zot: it carries no auth of its own.
The mesh grants named workloads method- and path-scoped
access, and the gateway route admits the node sources for
GET and HEAD only.

## Sync credential rotation

The sync credential is the existing 1Password item `Docker`.
Nothing is created for zot.
Rotation ends only when all three proofs hold: the new credential
works, the old credential no longer authenticates, and the old
credential is revoked at the provider. A rotation that skips
revocation is not complete.

## Node changes

A node addition or replacement re-runs `generate.py --cidrs` in the
same change, so the route SecurityPolicy always matches the live
node pod CIDRs.
